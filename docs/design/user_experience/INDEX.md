## ✅ Release Quality Check

- [ ] Critical flows work fully with a keyboard, including dialogs and error recovery.
- [ ] Reduced motion, empty/loading/error states, and performance budgets have been tested.
- [ ] Each important flow has at least one usability or product signal.
